Core Algorithmic Optimizations (Any R×C Grid up to N ≤ 64)
1. Candidate Masks: 64-bit O(1) tracking up to N=64
2. Worklist Propagation: Targeted cell re-checks
3. Undo Log: O(1) LIFO board restoration
4. Hidden Singles: seenOnce/seenTwice bitmasks
5. Live Empty List: Doubly linked O(1) splicing
6. MRV Selection: Scans only live empty cells
7. Unit Lookups: Precomputed 3×N caches
8. Generic Sub-Grids: Supports any R×C (4×4 to 64×64)
